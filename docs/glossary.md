# 用語集

fandhe-workshop の文書とコードで使う主な用語をまとめます。
各用語は「定義」「補足（どこで使うか）」「関連語」の順で書いています。
Step の状態・構造定義・教材パックの構成などは、private の仕様リポジトリ（`docs/spec`）の内容を要約したもので、仕様との一致は公開前にメンテナーが確認します。
crate 名などの名前は仮称です（[`README.md`](../README.md) の「仮称の一覧」と [`docs/architecture.md`](./architecture.md) を参照）。

## 章

**定義**: 教材を区切る単位です。複数の Step を順番に持ちます。

**補足**: 教材パックの `chapters/<章>/` ディレクトリに置かれます。章の順序と属性は構造定義に書き、本文は Markdown で書きます。

**関連語**: [Step](#step)・[教材パック](#教材パック)・[構造定義](#構造定義)

## Step

**定義**: 章の中の、受講者が 1 つずつ進める単位です。入力条件・状態変化・完了条件・ヒントを持ちます。

**補足**: Step の状態は次の 5 つです。通常は `not_started`・`entered`・`accepted`・`achieved` の順に進み、`skipped` は途中開始などで進行を飛ばした場合の分岐です（達成の後ろに続く状態ではありません）。

| 状態 | 意味 |
|---|---|
| `not_started` | まだ始めていない |
| `entered` | Step に入った |
| `accepted` | 入力が受け付けられた |
| `achieved` | 完了条件を満たした（達成） |
| `skipped` | 途中開始などで飛ばした（達成ではない） |

受け付けることと達成することは分けて扱います。確認の操作を省く教材は、省くことを明示して書きます。

**関連語**: [章](#章)・[世界状態](#世界状態)・[語彙](#語彙)

## IR

**定義**: 教材パックを、ビルド時に検証・コンパイルして作る JSON の中間表現です。形式の版 `ir_format` を持ちます。

**補足**: 実行時にエンジンが読むのは IR だけで、Markdown や構造定義は読みません。IR は未信頼の入力として扱い、上限を超えるものは拒否します。

**関連語**: [教材パック](#教材パック)・[構造定義](#構造定義)・[中核](#中核)

## 語彙

**定義**: 構造定義で使える、宣言的な語の集合です。入力方式・条件・状態変化・確認・拒否の分類・ビューの種類などを含みます。

**補足**: スクリプトや式を書く欄はなく、未知の項目は読み込み時に拒否されます。語彙の版は、IR の版 `ir_format` とは別に管理します。教材ごとの違いは、語彙の組み合わせと、名前を付けた拡張点で表します。語ごとの語彙の版と名前つき拡張点 EP-1〜EP-13 の名前・版は `docs/vocabulary/vocabulary.md` に固定しています。

**関連語**: [構造定義](#構造定義)・[IR](#ir)・[Step](#step)

## 教材パック

**定義**: 1 つの教材を構成するデータ一式です。本文の Markdown・構造定義・練習データ・教材テスト・参照元の版で構成します。

**補足**: 教材は別のリポジトリで作成します。エンジンは特定の教材の知識を持ちません。

**関連語**: [章](#章)・[構造定義](#構造定義)・[IR](#ir)

## 構造定義

**定義**: 教材作成者が書く、YAML 系の構造化データの層です。章・Step・入力条件・状態変化・完了条件・ヒントなどを、語彙の範囲で宣言します。

**関連語**: [語彙](#語彙)・[教材パック](#教材パック)

## 世界状態

**定義**: 教材の中で操作の対象になる、架空の成果物（ファイル・差分・Issue・PR／CI の状態など）の状態です。

**補足**: ターミナル風の操作に応じて世界状態が変わり、その変化が Step の完了条件の判定に使われます。

**関連語**: [Step](#step)・[中核](#中核)

## 中核

**定義**: DOM に依存しない、純 Rust で書く部分です。IR を読み、操作に応じて状態を進めます。

**補足**: `docs/architecture.md` の `core` crate（仮称）にあたります。表示の層からは、`Session` の操作と `Projection` を通して使われます。

**関連語**: [IR](#ir)・[世界状態](#世界状態)

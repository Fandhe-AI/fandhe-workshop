# 右の画面の試験の束の定義（TASK-458 1/3。TERM-40）。一か所の正。
#
# 目的: 入力欄のキー処理（Enter・Tab・Space の状態に応じた preventDefault と、root の外の Esc）の受け持ちを
#   どう変えても、右の画面の操作の結果（TERM-1〜TERM-14・TERM-23）が変わらないことを、1 つの回帰として流せるようにする。
#   実行は scripts/test-right-pane.sh（make test-right-pane）。定義の静的な検査は scripts/check-right-pane-suite.sh
#   （make check に含む）。件数の基準は right-pane-baseline.txt（2/3。docs/testing.md 5.514）、置き換えの前後の比較は 5.515（3/3）。
#
# 入れる規則:
#   screen = 冒頭で TASK-438・439・440・441・442・450・451・452 のどれかを出所として名乗る画面の試験。
#   helper = screen が直接 import する部品 X.mjs に自己確認 X.test.mjs があるもの（部品が壊れて画面の試験が空振りするのを防ぐ）。
#            間接の import は追わない。
# 入れないもの: 8 タスクに触れるだけの試験（enter-submit・esc-key・shift-tab・tab-cycle・tab-trap・reject-lines・
#   run-status・log-lines-xss・restore-cancel・approval-flow・choice-answer・keyboard-confirm など）と、
#   不変条件の側の試験（key-invariants・field-space・submit-disabled。TASK-351・TASK-352 の持ち分）。
#
# 必須の集合（TERM-1〜TERM-14・TERM-23 と 8 タスク）は検査スクリプト側に固定してある。ここの行を消しても要件は消えない。
#
# 書式（区切りは |）:
#   file|<試験ファイル名>|<screen|helper>|<出所。screen は TASK-nnn、helper は部品の .mjs 名>
#   term|<TERM の ID>|<auto|proxy>|<束の screen の試験ファイル（, 区切り）>|<補足。proxy は必須>
#   auto  = 束のファイルが、その項目を判定つきで確かめる。
#   proxy = 自動で確かめられる部分（模擬・自動操作・観察）だけを束に入れる。人の確認や判定の無い部分は束の外。

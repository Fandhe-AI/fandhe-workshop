メモ・Slack など）で開いてコピーし、教材の入力欄に Cmd+V で貼り付けます。

| ID | 見本 | 操作 | 合とする条件 | 結果 | 使ったアプリ | メモ |

## Tab の出入り（K 項目）

いまの画面の操作領域の Tab の順は、入力欄 → 送信 → OS の選択 → 停止 → 早送りの切り替え です（2026-11-18 の観察）。
入力欄の前は、本文の中のリンクです。

| ID | 準備 | 操作 | 合とする条件 | 結果 | メモ |
| --- | --- | --- | --- | --- | --- |
| K-01 | 入力欄にフォーカス、入力は空 | Tab | フォーカスが送信ボタンへ移る。補完は起きない | | |
| K-02 | 送信ボタンにフォーカス | Shift+Tab | フォーカスが入力欄へ戻る | | |
| K-15 | ページを開き直し、フォーカスが画面のどこにも無い | Tab を何度も押して画面を一巡し、Shift+Tab でも逆に一巡する | 入力欄・送信ボタンを含むどの要素でも行き止まりにならず、最後の次はブラウザの枠か先頭へ出る（Tab の罠 0） | | |

補完（K-03）・候補の一覧の Esc（K-09）など、残りの K 項目は自動の試験で確かめています
（手順の元は `testdata/input-field-ime/test-data/key-procedures.md`。人の確認には数えません）。

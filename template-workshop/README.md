## ライセンス

この雛形は、エンジンと同じ `MIT OR Apache-2.0` で配布します。本文は同じディレクトリの [LICENSE-MIT](./LICENSE-MIT) と [LICENSE-APACHE](./LICENSE-APACHE) です。

雛形から教材 repo を作るときは、この 2 つのファイルとこの節を残してください。教材 repo の著作権者の表記と教材のライセンスの案内は、雛形の整備の中で別に扱います。

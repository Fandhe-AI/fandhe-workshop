## 人の評価に数えないこと

D-34 により、参加者による試行は行わず、利用者自身が確かめます。記録には必ず次の 1 文を書きます。

> 利用者自身の確認であり、参加者の試行ではない。人の評価（成功基準の証拠）には数えない。

AI の代理の確認（CDP による IME の模擬、自動ブラウザのキーボード操作、アクセシビリティツリーの観察）は、
この表の記録に数えません。AI は結果の欄を書きません。人が口頭や文で伝えた結果を、AI が書き写すのは構いません
（その場合は「書き写し: AI」と添えます）。

## 記録の様式

確認の 1 回ごとに、各確認表の「記録」の節へ次の見出しを足し、項目ごとの結果を表の欄に書きます。

| 欄 | 書くこと |
| --- | --- |
| 日付 | `YYYY-MM-DD` |
| 確かめた人 | 操作した人。観察者がいれば並べて書く |
| 確かめた版 | エンジンの commit（`git rev-parse --short HEAD`）、教材と教材の commit、macOS の版、Chrome の版、日本語入力の種類とライブ変換の入・切（VoiceOver の版は `voiceover.md` だけ） |
| 確かめ方 | 開いた URL の形（例: `fandhe-pack preview` の URL に `?start=s-1-1`） |
| 区分 | 上の「人の評価に数えないこと」の 1 文 |
| 結果 | 項目ごとに「合」「否」「未」のどれか。「否」はメモに何が起きたかを書く |
| 集計 | 確認表ごとの合計（例: 誤送信 0 件・送信漏れ 0 件・停止 0 件） |

「否」が出たら、記録を残したうえで起票を相談します（起票は利用者の了承の後。`.claude/rules/out-of-scope-tracking.md`）。
